# Reporte: proyecto preparado para GitHub

Se preparó el proyecto para subida correcta a GitHub sin usar la carga manual web.

## Archivos agregados

- `.gitignore`: evita subir dependencias, builds, variables privadas, cachés y archivos temporales.
- `SUBIR_A_GITHUB_SIN_ERRORES.md`: guía simple para publicar con GitHub Desktop o Git.
- `SUBIR_A_GITHUB_WINDOWS.bat`: script de Windows para inicializar Git, crear commit y subir al repositorio privado.
- `uploads/.gitkeep` y `backend/uploads/.gitkeep`: conserva carpetas necesarias sin subir archivos cargados por usuarios.

## Motivo

GitHub Web limita la carga manual cuando hay muchos archivos. Este proyecto debe subirse con GitHub Desktop o Git por consola/script.
