# Imperial Fitness — Sistema de retención, rachas, XP y gamificación

## Objetivo
Elevar retención, participación y dinamismo dentro de la app sin cargar al entrenador con registros manuales diarios.

## Qué incluye

### Cliente
- Panel de nivel, XP, monedas e insignias.
- Racha de entrenamiento.
- Racha nutricional.
- Racha de agua.
- Racha de sueño.
- Racha de progreso.
- Racha mental.
- Día Perfecto Imperial.
- Misiones diarias.
- Escudos Imperiales para proteger rachas.
- Notificaciones internas por nivel, insignias y rachas.

### Admin / Entrenador
- Panel interno de adherencia gamificada.
- Clientes que requieren seguimiento.
- Top disciplina semanal.
- Botón directo a WhatsApp cuando el cliente tiene teléfono registrado.
- Métricas internas no visibles para el cliente.

## Reglas de XP iniciales
- Entrenamiento registrado: +10 XP.
- Alimentación cumplida: +15 XP.
- Alimentación parcial: +5 XP.
- Día Perfecto Imperial: +25 XP.
- Agua registrada: +5 XP.
- Sueño registrado: +5 XP.
- Acción mental: +5 XP.
- Progreso registrado: +20 XP.
- Misiones diarias: bonus adicional.

## Rachas
- 3, 7, 14, 30, 60 y 100 días desbloquean insignias.
- Cada 15 días perfectos otorgan 1 Escudo Imperial.
- Si el cliente falla y tiene escudo, se consume para proteger la racha.

## Importante
Este módulo se apoya en el check-in diario ya implementado. Cuando el cliente registra entrenamiento/alimentación, el backend procesa automáticamente XP, rachas e insignias.
