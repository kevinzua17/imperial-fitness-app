# Checklist de prueba piloto - 10 a 20 usuarios

## Acceso

- [ ] El administrador inicia sesión.
- [ ] El entrenador inicia sesión.
- [ ] El cliente inicia sesión.
- [ ] Recuperación de contraseña envía correo.
- [ ] No se permite entrar con clave incorrecta repetidamente.

## Roles

- [ ] Admin ve gestión de usuarios.
- [ ] Entrenador ve clientes asignados.
- [ ] Cliente no ve panel administrativo.
- [ ] Cliente no accede a información de otros clientes.

## Rutinas

- [ ] Crear rutina.
- [ ] Asignar rutina a cliente.
- [ ] Cliente visualiza rutina desde celular.
- [ ] Cambios se guardan correctamente.

## Nutrición

- [ ] Crear plan alimenticio.
- [ ] Editar plan.
- [ ] Cliente visualiza dieta.

## Progreso

- [ ] Registrar peso, medidas o progreso.
- [ ] Subir foto de progreso.
- [ ] La foto se guarda en Cloudinary.
- [ ] La foto se visualiza correctamente después de cerrar sesión.

## Comunidad / chat / retos

- [ ] Publicación básica funciona.
- [ ] Chat básico funciona.
- [ ] Reto o recompensa se visualiza correctamente.

## Rendimiento

- [ ] App carga en menos de 3 segundos en WiFi.
- [ ] App carga de forma aceptable con datos móviles.
- [ ] No hay pantallas en blanco.
- [ ] No hay errores visibles en consola.

## APK

- [ ] APK instala en Android.
- [ ] APK abre sin pantalla blanca.
- [ ] APK conecta al backend real.
- [ ] Login funciona desde APK.
- [ ] Subida de imágenes funciona desde APK.

## Cierre del piloto

- [ ] Registrar errores encontrados.
- [ ] Priorizar fallas críticas.
- [ ] Corregir antes de pasar a 50-100 usuarios.
