Coloca el logo real en:

```text
public/logo-imperial-fitness.png
```

Luego ejecuta desde la raiz del proyecto:

```powershell
python generar_iconos_pwa.py
```

Esto creara:

```text
public/icons/icon-192.png
public/icons/icon-512.png
```

Estos iconos son los que usa la PWA para instalarse en Android/iPhone.
